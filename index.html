    🗂 このマップ

    📥 読み込み・バックアップ

    入れ子形式・id/parent の平坦形式・バックアップ形式に対応（1ファイル5MBまで、複数選択可）。JSONファイルを画面にドロップしても読み込めます。

    ゴミ箱
    ℹ️ 使い方と制約
    • キャンバスをクリックしてから Tab（子）／ Enter（同階層）で追加。
    • 右上の ? で全ショートカットを表示。
    • キャンバスで Esc を押して選択を外すと、Tab で他の操作へ移動できます。
    • データはこのブラウザ内（localStorage）にのみ保存されます。別の端末やブラウザとは同期されません。
    • ブラウザのサイト データを消去するとマップも消えます。定期的にバックアップしてください。
    • 共有リンクやリアルタイム共同編集には未対応です（ファイルで共有してください）。
    • 元に戻す履歴は、マップの切替やページ再読み込みでリセットされます。

    中心テーマを選んで Tab を押すと枝を追加できます。

    👋 MindFlow へようこそ

    1. ノードをクリックして選択
    2. Tab で子ノード、Enter で同じ階層に追加
    3. 文字を入力して Enter で確定
    4. ドラッグで移動、別のノードに重ねて付け替え

    変更はこのブラウザに自動保存されます。右上の「書き出し・共有」から画像やPDFにできます。

    操作ガイド

    書き出す

    Tab
    子ノードを追加して入力開始
    Enter
    同じ階層にノードを追加（入力中は確定）
    F2 / Space / ダブルクリック
    テキストを編集
    入力中 Shift+Enter
    改行
    入力中 Esc
    入力を取り消す
    Ctrl+V
    貼り付け（箇条書きテキストは階層付きで取り込み）

    整理する

    ドラッグ
    自由に移動。別のノードに重ねると子に、上端・下端に重ねると前後に移動
    Alt+↑↓
    同じ階層内で並べ替え
    Shift+Tab
    1つ上の階層へ移動
    Ctrl+/
    折りたたみ・展開
    Ctrl+D
    枝ごと複製
    Ctrl+C / X
    枝ごとコピー / 切り取り
    Ctrl+Enter
    完了・未完了の切り替え
    Delete / Backspace
    枝ごと削除（元に戻せます）

    見つける・表示

    ←→↑↓
    ノード間を移動
    Ctrl+F
    検索（Enterで次、Shift+Enterで前）
    F
    選択した枝だけを表示（フォーカス）
    Esc
    フォーカス解除 → 選択解除
    0 / + / -
    全体表示 / 拡大 / 縮小
    Shift+矢印
    画面を移動
    ホイール / Ctrl+ホイール
    画面の移動 / 拡大縮小（タッチではピンチ）

    その他

    Ctrl+Z
    元に戻す
    Ctrl+Shift+Z / Ctrl+Y
    やり直し
    Ctrl+S
    すぐに保存（通常は自動保存）
    ?
    このガイドを開く

    Mac では Ctrl の代わりに ⌘ も使えます。キーボード操作はキャンバスを選択している間に有効です。
